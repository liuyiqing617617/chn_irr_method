# China Irrigation Method Dataset

This repository contains the R code used to generate the China irrigation
method dataset at 1-km resolution and reproduce the data-driven figures in the
associated manuscript. The released data and the inputs required by the
scripts are hosted separately on Figshare to keep the GitHub repository
lightweight.

## Data availability

The dataset and reproducibility inputs are available from Figshare:

<https://doi.org/10.6084/m9.figshare.34022247>

Download `input_data.zip` and extract it in the repository root. To reproduce
the manuscript figures without regenerating the raster products, also download
the ten released GeoTIFFs and place them in `data/`.

After downloading the data, the project should have the following structure:

```text
chn_irr_method/
|-- code/
|   |-- 01_generate_products.R
|   |-- 02_plot_figure2_ISI.R
|   |-- 03_plot_figure3_irrigation_methods.R
|   |-- 04_plot_figure4_validation.R
|   `-- 05_plot_figure5_consistency.R
|-- input_data/
|   |-- boundaries/
|   |-- indicator_allocations/
|   |-- indicators/
|   |-- irrigation_mask/
|   `-- statistics/
|-- data/
`-- README.md
```

The `data/` and `input_data/` directories are intentionally not stored in the
GitHub repository.

## Released products

Products are provided for 2000, 2005, 2010, 2015, and 2020:

- `chn_irr_method_yyyy_1km.tif` contains the irrigation method of each
  cropland pixel. Values are 0 (rainfed), 1 (surface irrigation), 2 (sprinkler
  irrigation), and 3 (drip or micro irrigation). Non-cropland pixels are
  NoData (stored as 255 in the UInt8 GeoTIFFs).
- `chn_consistency_yyyy_1km.tif` contains the classification consistency of
  sprinkler- and micro-irrigated pixels, calculated as `Pi/Pmax`, where `Pi`
  is the priority score of the assigned irrigation method and `Pmax = 415`.
  Values range from 0 to 1. Rainfed, surface-irrigated, and non-cropland pixels
  are NoData (stored as -9999 in the Float32 GeoTIFFs).

All released GeoTIFFs use the WGS84 coordinate reference system and have a
nominal spatial resolution of 1 km.

## Software requirements

The analysis requires R and the following packages:

```r
install.packages(c(
  "cowplot", "dplyr", "ggplot2", "RColorBrewer",
  "readxl", "sf", "terra", "tidyr"
))
```

The geospatial packages `sf` and `terra` may require system libraries. Refer to
their installation documentation if they are not available on your platform.

## Reproducing the dataset

From the repository root, extract `input_data.zip`, create the output
directory, and run:

```bash
mkdir -p data
Rscript code/01_generate_products.R
```

The script performs the complete province-constrained allocation and writes
the ten released GeoTIFFs to `data/`. Set `FIGSHARE_DATA_DIR` to write the
products to a different directory:

```bash
FIGSHARE_DATA_DIR=/path/to/output Rscript code/01_generate_products.R
```

## Reproducing the figures

Each main-text figure is generated independently:

```bash
Rscript code/02_plot_figure2_ISI.R
Rscript code/03_plot_figure3_irrigation_methods.R
Rscript code/04_plot_figure4_validation.R
Rscript code/05_plot_figure5_consistency.R
```

By default, figures are written to `figures/`. Set `FIGSHARE_OUTPUT_DIR` to use
another output directory. Figure 1 is a conceptual workflow diagram and is not
generated by an R script.

The plotting scripts calculate the required zonal summaries, temporal
matching, validation statistics, and correlations directly from the supplied
rasters, boundaries, and statistical workbooks. Precomputed plotting tables
are not required.

## Code overview

- `01_generate_products.R`: generates the irrigation-method and consistency
  GeoTIFFs for all five mapping years.
- `02_plot_figure2_ISI.R`: reproduces the ISI figure.
- `03_plot_figure3_irrigation_methods.R`: reproduces the spatial and temporal
  irrigation-method results.
- `04_plot_figure4_validation.R`: performs basin- and prefecture-level
  validation and reproduces the validation figure.
- `05_plot_figure5_consistency.R`: reproduces the classification-consistency
  figure.
